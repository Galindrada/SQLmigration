# Football Club Overlay Generator for CapCut

Create professional football match overlays to use in CapCut for displaying final scores, competitions, and goal scorers.

## Features

- **Multiple Club Support**: Pre-configured with 15 popular football clubs including Barcelona, Real Madrid, Manchester United, Liverpool, etc.
- **Professional Styles**: 4 different overlay styles (Modern, Classic, Minimal, Champions League)
- **Complete Match Information**: Display final scores, competition names, matchdays, dates, and goal scorers
- **Real-time Preview**: See your overlay update in real-time as you fill in the details
- **High-Quality Export**: Download overlays as PNG images with transparent backgrounds
- **Mobile Responsive**: Works on desktop and mobile devices

## How to Use

1. **Open the Application**: Open `index.html` in your web browser
2. **Select Teams**: Choose home and away teams from the dropdown menus
3. **Enter Scores**: Input the final scores for both teams
4. **Add Goal Scorers**: List the goal scorers with their scoring times (e.g., "Messi 23'")
5. **Competition Details**: Enter the competition name, matchday, and date
6. **Choose Style**: Select from 4 different overlay styles
7. **Preview**: Watch your overlay update in real-time
8. **Download**: Click "Download as PNG" to save the overlay

## Using in CapCut

1. **Import to CapCut**: 
   - Open CapCut and create a new project
   - Import your video footage
   - Add the downloaded PNG overlay as an "Overlay" element

2. **Position the Overlay**:
   - Drag and resize the overlay to fit your video
   - The PNG has a transparent background, so it will blend seamlessly

3. **Timing**:
   - Set the overlay to appear when you want to show the final result
   - You can animate the overlay entrance/exit for better effect

## Tips for Best Results

1. **Image Quality**: The overlay exports at 2x scale for crisp quality in CapCut
2. **Goal Scorers Format**: Use format like "Player Name 23'" for best appearance
3. **Competition Names**: Use full names like "UEFA Champions League" or "Premier League"
4. **Mobile Use**: The interface is responsive and works on tablets and phones
