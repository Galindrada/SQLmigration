Booster edition builder

Create an edition, add limited definitions (how many of each card go into the run), then Generate card pool. The system builds exactly boosters × cards per pack cards: regular pulls (by your rarity %) plus limited copies, shuffled together and split into packs in order (pack #1, #2, … #400). Users cannot buy until the pool exists. Mark editions Show in shop, upload booster layout art (pack images on Fantasy), and use Disabled to hide an edition without deleting it. Delete edition is only allowed before any pack is sold. Only one edition can be active (legacy default when no pack is chosen). Access: env FANTASY_BUILDER_USER_IDS (comma-separated user ids); if unset, any logged-in user can open this page (dev only).
